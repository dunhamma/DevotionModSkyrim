# Prisma glyph roster — refinement flags

Self-assessed flags from authoring the 49-glyph roster (Princes, cultural pantheons, concept marks).
Contact sheets: `scratch/prisma-art/batch{1-5}_*.png`. Drop-in data: `PrismaGlyph_FullRoster_SVGData.md`.
These are the marks I'd revisit before they're final; the rest read cleanly at toast size (24px).

## Cross-cutting note — solar-mark collision
Too many marks default to a **rayed sun/disc**: `meridia`, `molag-bal`, `namira`, `magnus`, `broad`.
Recommend only **one or two** stay solar (`meridia` is the natural keeper — "radiant beacon"); push the
others to their distinctive motifs (above) so the set doesn't blur at small size.
