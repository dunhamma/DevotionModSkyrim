# Aggregate broad worship by logical devotional event

Status: accepted

Imperial Divines, Nord Old Ways, and Nord Nine Divines use manager-owned broad pantheon pools rather than aggregate deity records or sums of deity piety. Each logical devotional act contributes the strongest applied eligible positive delta, or the most severe eligible negative delta when there is no positive, because summing fan-out would reward the number of authored reactions instead of the weight of the player's deed.
