Moving functions out of the manager broke every gate that read only the manager file: positive checks failed and negated ones passed vacuously, so gates reported red about code that was present and correct, just elsewhere. One shared resolver now reads the whole module family — strictly additive, and automatically correct for the three extractions still to come. The reference case, the substrate-pacing gate, went from 28 failures to zero. One gate had been worse than red: it was blind and generative, quietly writing 35 fabricated “under-floor” rows into a tracked ledger. The 12 gates still failing need the live game tree, or are real findings kept red on purpose rather than papered over.
