# ORIGIN base dedup -- concrete-adapter cast safety audit

**Date:** 2026-08-19 - **Kind:** LIVING analysis (input to the Phase C switchboard-removal decision)

## Why this exists

Phase C's real work is not "delete the 627 duplicate bodies" -- 532 of them are the
polymorphic dispatch SURFACE that 473 external base-typed calls (`OriginRuntime.<lanefn>`)
compile against (73 were provably dead and already deleted, commit 40877ee6). To remove the
rest, each external call must stop naming the base method. The owner-preferred mechanism is a
concrete-adapter cast: `OriginRuntime.D()` -> `(OriginRuntime as PDV_OriginRuntime_<R>).D()`.
This audit maps, per externally-named duplicate, whether that cast is behavior-safe.

## The safety criterion (rigorous)

`OriginRuntime` is always bound to the player's own-race adapter, so the cast differs from
today's override dispatch ONLY for a player whose race != R at the call site:
- **R player:** cast succeeds -> adapter.D() -- identical to today. Always safe.
- **non-R player:** cast -> None -> D returns the type default; today the BASE body runs.

So a cast is safe iff, for every call site, either (A) a non-R player never reaches it (the
site is race-R-gated upstream), or (B) the base body returns the type default for a non-R
player anyway. Verdicts below use STRONG gating only (an explicit `ORIGIN_<R>` index compare,
an `Is<R>Origin()` check, or an enclosing function named for the race); weaker hints were
demoted to review on purpose.

## Distribution (292 externally-named duplicates)

| Verdict | Count | Meaning |
|---|---:|---|
| **A** call-sites R-gated | 171 | high-confidence safe to cast |
| **B** base returns default | 4 | safe to cast |
| **C** needs review | 116 | unguarded site + base does non-trivial work |
| **MULTI-RACE** | 1 | duplicated across >1 adapter; cast target not single-valued |

**175 are high-confidence safe; 117 need a human.** Within the 116 C: 39 are read-only
(Get/Is/Can -- lowest risk, worst case a non-R player reads a default) and 77 are
side-effecting (24 Sync, 15 Handle, 6 Ensure, ...) -- those get careful eyes first, because a
cast that no-ops a real side effect for a non-R player is the only way this bites.

## Recommendation

Cast the 175 A+B now (scripted, then compile 0/0 + parity per wave), and work the 116 C in two
passes: the 39 read-only quickly, the 77 side-effecting deliberately. Every C that review
clears joins the cast set; any that can't stays a base declaration (or gets a keyed virtual).
